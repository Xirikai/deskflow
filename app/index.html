ОСТАВИТЬ ПОД РУКОЙ

Твоя полка

Файлы, текст и ссылки для следующего действия.

Перетащи файлы на полку — здесь сохранятся их отдельные копии.

Файлы можно перетащить с полки в проводник. Удаление с полки не удаляет оригинал.

МОЖНО ВЕРНУТЬСЯ НАЗАД

История действий

Отмена сортировки и переименования с проверкой сохранности файлов.

Твоё пространство

В публичную сборку FFmpeg не включён. Подключите его один раз для удаления звука из видео. Остальные функции работают без него.

Все данные и обработка остаются на компьютере. Передача между устройствами в эту версию не входит.
