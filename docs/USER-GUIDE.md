# DeskFlow 1.0.1 — инструменты для Windows

## Запуск

Откройте DeskFlow-Windows-v1.0.1.exe двойным нажатием. Это переносимая версия для Windows 10/11 x64. Node.js и Python для готового EXE не нужны. FFmpeg для видео подключается отдельно через настройки. Первый запуск включает распаковку встроенных компонентов и может занять время. Размер EXE около 397 МиБ: внутри оболочка Windows и библиотеки обработки изображений. FFmpeg в публичный EXE не включён.

Это отдельное приложение. Personal Learning OS и Orbit оно не изменяет. Передача между телефоном и компьютером («Карман») не включена. Android-версии в этом проекте пока нет.

## Светлая и тёмная тема

Кнопка солнца/луны справа сверху переключает светлую и тёмную тему. В настройках можно выбрать «Как в Windows». Выбор сохраняется после выхода. Значок возле часов открывает приложение двойным нажатием.

Ctrl+Shift+Space открывает быстрый запуск или скрывает уже активное окно. Если сочетание занято другой программой, приложение сообщает об этом в настройках; открыть его можно через значок возле часов. По умолчанию крестик сворачивает приложение в этот значок. Для полного выхода: меню значка → «Выход» или настройки → «Выйти из приложения». В настройках можно отключить сворачивание при закрытии.

## Скриншоты

Нажмите «Сделать снимок экрана». DeskFlow на мгновение скрывается, получает изображение и возвращается. При нескольких экранах выберите нужный. Также можно открыть своё изображение в редакторе.

Инструменты: обрезка выделенной области, стрелка, рамка, непрозрачное скрытие области, подпись и карандаш. Для подписи сначала впишите текст в поле над изображением, затем нажмите в нужном месте. Для остальных инструментов проведите мышью. Доступна отмена последних восьми действий.

Изображение можно сохранить как PNG, скопировать, отправить на полку либо в мастер файлов для уменьшения и преобразования в JPEG/WebP/PNG. Распознавание текста работает локально средствами Windows. Результат можно поправить и скопировать. Язык зависит от установленных языковых компонентов Windows; если подходящего компонента нет, приложение объяснит причину. Большие снимки для OCR можно сначала обрезать. Строгое качество распознавания для любого изображения не гарантируется: мелкий, повёрнутый или нечёткий текст распознаётся хуже.

## Порядок в файлах

«Разложить папку» анализирует обычные файлы верхнего уровня выбранной папки. Категории: изображения, документы, видео, музыка, архивы, установщики, другое. Скрытые файлы, ссылки, вложенные папки и частичные загрузки пропускаются. Сначала показывается таблица: что и куда переместится. Можно снять отметку с отдельных файлов и только после этого применить изменения.

Массовое переименование: задайте шаблон и начальный номер, затем выберите файлы. {name} обозначает старое имя, {n} — номер с ведущими нулями. Например, Фото-{n} даст Фото-001.jpg, Фото-002.jpg. Расширение сохраняется. Порядок определяется порядком выбранных файлов.

При совпадении имён добавляется номер; существующий файл не перезаписывается. Перед удалением исходной копии проверяется содержимое и записывается журнал восстановления. Если файл изменился после предпросмотра, операция для него не выполняется. Большие файлы могут обрабатываться дольше из-за копирования и проверки.

В истории можно отменить сортировку или переименование. Изменённые после операции файлы и занятые другими файлами исходные имена автоматически не трогаются. Ошибки показываются отдельно. Если часть файлов уже отменена, повторная отмена проверяет только оставшиеся записи.

## Мастер файлов

- Изображения: входные PNG, JPEG, WebP, GIF, TIFF, AVIF при поддержке формата встроенной библиотекой. Выход JPEG, PNG, WebP. Настройка максимальной ширины и качества; маленькие картинки не увеличиваются. PNG без потерь, качество применяется к JPEG/WebP. Результат — отдельный файл; метаданные исходного изображения не переносятся. Для анимированных изображений обрабатывается первый кадр.
- Фото → PDF: по странице на изображение, формат A4, автоматическая ориентация листа. После выбора файлов порядок меняется стрелками вверх/вниз.
- Видео без звука: отдельная копия с видеодорожками без аудио, без перекодирования видео. Поддерживаются обычные контейнеры MP4, MKV, MOV, AVI, WebM, M4V; повреждённый файл или несовместимая дорожка выводятся как ошибка.

Файлы можно выбрать кнопкой или перетащить в область. Папка результата выбирается отдельно. Готовые результаты можно показать в проводнике. Изображений в одной операции — до 100, видео — до 20; изображения ограничены 80 мегапикселями для контроля памяти. Переименование находится в разделе «Порядок в файлах».

## Быстрый запуск

Отображаются зарегистрированные в меню «Пуск» программы текущего пользователя. Поиск работает по названиям. Можно добавить собственный файл, программу, папку или ссылку HTTP/HTTPS. Enter в строке поиска открывает первый результат. Добавленные вручную ярлыки можно убрать, сами программы и файлы при этом не удаляются. Приложение не устанавливает программы и не запрашивает доступ к вашим аккаунтам.

## Пульт звука

Список реальных устройств воспроизведения Windows, выбор основного устройства, общая громкость и отключение звука. Ниже — громкость программ с активными звуковыми сессиями. Чтобы программа появилась, запустите воспроизведение в ней и нажмите «Обновить устройства».

Профиль сохраняет основное устройство, его громкость/отключение звука и громкость активных программ. При применении восстанавливает параметры и совпавшие по имени активные программы. Приложение не запускает закрытые программы и не регулирует микрофон. Переключение основного устройства применяется к ролям воспроизведения Windows; некоторые программы удерживают ранее выбранное устройство до перезапуска воспроизведения.

## Полка

Добавляйте файлы, текст и ссылки. При добавлении файла создаётся отдельная локальная копия; исходник остаётся на месте. Можно выделить несколько элементов, сохранить их в папку либо скопировать файлы в буфер для вставки в проводник через Ctrl+V. Файлы также можно перетаскивать с карточки в проводник. Текст и ссылки копируются как текст. Для смешанного выбора используйте сохранение в папку.

Убранная с полки копия файла перемещается в корзину Windows. Исходный файл не затрагивается. Текст и ссылки при удалении убираются из списка. Полка не очищается автоматически по времени.

## Данные и приватность

Все пользовательские данные DeskFlow хранятся локально в %APPDATA%/DeskFlow: deskflow.json, история операций и копии полки. Снимки экрана не отправляются на сервер. OCR и преобразования работают без интернета. Ссылки открываются обычным браузером, а программы запускаются только по вашему нажатию. Автозапуск Windows и автоматическое обновление не включены.

Копию папки %APPDATA%/DeskFlow можно сохранить при полностью закрытом приложении. Для переноса на другой ноутбук ярлыки, пути истории и устройства звука могут потребовать перенастройки.

## Что проверено

14 автоматических тестов на реальных тестовых файлах: сортировка, совпадение имён, изменение файлов после предпросмотра, отмена, прерванное копирование, переименование, сохранение настроек, преобразование изображений, страницы PDF и удаление аудио из тестового видео.

На этом ноутбуке проверены реальные аудиоустройства и их чтение встроенным помощником; Windows OCR распознал «DESKFLOW OCR TEST 12345»; обнаружены зарегистрированные программы Windows. В настоящем окне проверены запуск, переключение темы с записью настройки, открытие тестового изображения, редактор, распознавание текста через интерфейс и отображение звукового устройства. Обработку пользовательских загрузок при проверке не выполняли. Разные модели аудиоустройств и все сочетания видеоформатов не проверялись.

## Сборка из исходников

Требуется Node.js 22+ и Windows. Выполните npm ci, npm run setup, npm start. Для EXE: npm run build. Аудиопомощник компилируется из native/Audio.cs; NAudio загружается из NuGet с проверкой SHA-256. Готовые DLL/EXE в Git не включаются.

Встроенные сторонние библиотеки и ссылки на их исходники перечислены в THIRD-PARTY.md. Папки тестовых профилей, личные настройки и node_modules в исходный архив не включаются.
