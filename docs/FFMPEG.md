# FFmpeg для видео

В публичной версии 1.0.1 FFmpeg не распространяется вместе с DeskFlow. Для остальных инструментов он не нужен.

1. Откройте [официальную страницу FFmpeg](https://ffmpeg.org/download.html) и выберите Windows-сборку одного из указанных там поставщиков.
2. Распакуйте пакет в постоянную папку. Внутри найдите `bin/ffmpeg.exe`.
3. В DeskFlow откройте Настройки → Выбрать ffmpeg.exe. Укажите этот файл.
4. Вернитесь в Мастер файлов → Видео без звука.

Также поддерживается FFmpeg в PATH, рядом с переносимым EXE либо переменная DESKFLOW_FFMPEG_BIN для разработки. Приложение не загружает и не запускает установщик FFmpeg автоматически. Версия 6.1.1 проверена на тестовом видео; совместимость со всеми контейнерами не заявляется.

У разных сборок FFmpeg разные наборы кодеков и лицензионные условия. См. [официальную информацию](https://ffmpeg.org/legal.html).
